# Dependency and packaging scope

The mathematical files and three original source-checking drivers are exported byte-for-byte. Their SHA-256 identities are sealed in [SOURCE-PROVENANCE.json](manifests/SOURCE-PROVENANCE.json). The active verification wrappers cover the full 133-module closure, actual elaborated statements, all-project axioms and logical-library replay.

The combined portable Lake package uses namespace-preserving library roots for the included 1D and HD sources, replacing the original projects' external/private local dependency relationship with included source files. This is a packaging configuration; mathematical file bytes, Lean options applicable to those libraries, Lean version and Mathlib revision are preserved. [lakefile.toml](lean/lakefile.toml) and [lake-manifest.json](lean/lake-manifest.json) are the complete portable configuration. All nine dependency Git URLs are public upstream URLs and every revision is a full pinned SHA.

The clean-staging changes are limited to documentation, privacy inspection and path-neutral receipt packaging. The mathematical axiom/fingerprint/kernel replay drivers and comparison logic are unchanged. The historical disclosure-allowing scanner is replaced by a strict scanner with no inherited exceptions; both PDF content and all new reachable Git history are examined. A fixed-version, SHA-256-pinned `pypdf` wheel is the only added Python dependency and is used solely for PDF inspection. Poppler supplies a second independent PDF text extractor.

The runner retains all original mathematical checks, fail-closed behavior, exit statuses, timeouts and no-retry semantics. Python interpreter commands are recorded as `python3` rather than a personal absolute executable path, and evidence arguments are relative to the checkout. Hosted CI runner paths, if present, are public technical provenance. No private path is a required build input. Source-integrity manifests are updated transparently for the new packaging and documentation hashes; original sealed mathematical hashes are never replaced.
