All 133 mathematical modules are included. Public comments in 28 files were privacy-sanitized; **their file hashes differ from the original frozen versions**. Every byte outside comments and every source line count is unchanged, as bound by [comment projection baselines](manifests/COMMENT-PROJECTION-BASELINES.json). The original source-checking drivers remain byte-identical; their mathematical verification logic is retained. Additional checks compare approved code projections and full elaborated type/dependency records.

The combined Lake package uses namespace-preserving roots for both included libraries. It replaces the original external/local source dependency with included source files. Mathematical imports, Lean options, Lean version and Mathlib revision are unchanged. [lakefile.toml](lean/lakefile.toml) and [lake-manifest.json](lean/lake-manifest.json) fix all nine public dependency URLs and full revisions. No private checkout or machine-specific path is a build input.

The runner retains every earlier mandatory build, axiom, frozen-fingerprint and project-replay check, timeout, raw exit-status record and fail-closed behavior. It adds exact approved-code projection checks, all-field registry comparison and sharing-preserving elaborated type/dependency comparison for every own-library declaration. These changes do not relax an existing mathematical gate. Unsupported comment-eraser grammar fails closed.

The SHA-256-pinned public `pypdf` wheel serves only PDF inspection; Poppler provides an independent extractor. Automated file/history/PDF screening is separate from contextual privacy review. Daniel Zhou's exact supplied documents retain their owner-authorized historical source references; his private Lean development is not included or a dependency.

New public source/checker manifests cover the privacy variants and checking inputs. The original frozen source manifests remain unchanged privately, and the 54/97 approved declaration fingerprint baselines remain unchanged. New verification evidence must identify the actual candidate commit; earlier staging runs cannot substitute for fresh candidate verification.
